<div align="center"><h1>TikTok Hushfeed</h1></div>

<p align="center"><b>Automatically builds and publishes patched TikTok APKs & Magisk/KernelSU Modules whenever new Hushfeed patches are released.</b></p>

---

## 📥 Download

Download the latest builds from [GitHub Releases](https://github.com/Psyquix/xx/releases).

- **Stable** - Latest stable Hushfeed patch release
- **APK** - Standalone patched APK (non-root)
- **Module** - Magisk/KernelSU module (root)
